ServerManager

On the desktop open Settings → Remote access, turn it on, then press Pair a phone. Type the eight-character code shown there.

The code works once and expires in five minutes. This browser will be able to view your servers, start and stop them, and read their consoles. Sending console commands is granted separately on the desktop, and you can revoke this browser there at any time.

This browser is not permitted to send console commands. Grant it on the desktop under Settings → Remote access.
